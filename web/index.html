Controls how memories are retrieved and injected into conversations. Changes here affect response quality.

🤖 Agent Roles

          
Define what each agent role does. These are injected into the system prompt when an agent is spawned with that role.

          


          
⚙️ Runtime Configuration

          
Controls concurrency, safety limits, and circuit breaker behavior. Changes apply immediately without restart.


          

            
          


          
Concurrency Limits

          
How many agents can run simultaneously. Prevents API rate limits and resource exhaustion.

          

            

              
              
              
Total agents allowed across all providers at once.

            

            

              
              
              
Max concurrent DeepSeek agents. Lower this if you hit rate limits.

            

            

              
              
              
Max concurrent Qwen agents. Keep low — Qwen is used for fallback/orchestration.

            

          


          
Circuit Breaker

          
Auto-pauses a provider after repeated failures to avoid burning tokens on a broken endpoint.

          

            

              
              
              
Number of consecutive failures before the provider is temporarily disabled.

            

            

              
              
              
How long to wait before retrying a tripped provider. 60s is a good default.

            

          


          
Loop Safety Limits

          
Prevents runaway agents from looping forever or hammering tools endlessly.

          

            

              
              
              
Maximum LLM call cycles per agent task. Each iteration = one model response + optional tool calls. 25 handles most tasks.

            

            

              
              
              
Stops the agent if it calls tools this many times in a row without producing a text response. Catches stuck tool loops.

            

            

              
              
              
Hard cap on total tool invocations per task. Prevents infinite file reads or API calls even across multiple iterations.

            

          


          
🎓 Teacher (Escalation)

          
When an agent gets stuck or loops, the teacher model intervenes with guidance and can restructure the agent's todo list. Uses its own browser profile for authentication.

          

            

              
            

            

              
              
              
The model that intervenes when agents are stuck. Should be your strongest model.

            

            

              
              
              
Browser profile the teacher uses for Qwen authentication. Leave empty for default/active profile.
